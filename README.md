# Thiranex-Housing-EDA
# Housing Data Exploratory Data Analysis (EDA)

## Overview

This project performs Exploratory Data Analysis (EDA) on a Housing dataset to identify trends, patterns, and factors affecting house prices.

The analysis includes statistical summaries, correlation analysis, visualizations, and key business insights.

---

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

---

## Dataset Information

The dataset contains housing information including:

* Price
* Area
* Bedrooms
* Bathrooms
* Stories
* Parking
* Main Road Access
* Guest Room Availability
* Basement
* Air Conditioning
* Preferred Area
* Furnishing Status

---

## Analysis Performed

### Data Inspection

* Dataset shape
* Data types
* Missing values analysis

### Statistical Analysis

* Descriptive statistics
* Numerical feature analysis

### Visualizations

* House Price Distribution
* Correlation Heatmap
* Area vs Price Scatter Plot
* Bedrooms vs Price Box Plot

### Correlation Analysis

* Identification of features most related to house prices

---

## Key Findings

* Area has a strong positive influence on house prices.
* Bathrooms and stories contribute significantly to property value.
* Amenities increase property prices.
* The dataset contains no missing values.
